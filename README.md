## フォルダ構成

```
circuit-lab/
├─ README.md   この説明書
├─ CLAUDE.md   Claude 用のプロジェクトメモ
├─ .gitignore  git に入れないファイルの指定
├─ src/        画面とプログラム本体（React コンポーネント・シミュレーション計算）
├─ public/     そのまま公開する静的ファイル（画像・アイコンなど）
├─ tests/      テスト
└─ docs/       要件メモ・設計メモ（公開されない）
```

## 技術

- TypeScript + React（Vite）
- サーバー不要。計算・表示はすべてブラウザ内で行う
